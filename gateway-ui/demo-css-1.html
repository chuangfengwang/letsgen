对称渐变设计

本页面的渐变效果是完全对称的。从页面最左侧边缘开始，紫色(#8b5cf6)最浓， 随着向中心移动，逐渐变为蓝色(#3b82f6)然后红色(#ef4444)，在到达内容区域前变为透明。 右侧边缘以完全相同的方式从透明渐变回紫色。

渐变参数

渐变方向 从边缘向内容区域
对称性 两侧完全对称
渐变范围 边缘到内容边界
颜色过渡 紫 → 蓝 → 红 → 透明

技术实现

使用CSS线性渐变创建对称效果，通过精确控制色标位置实现两侧完全相同的渐变。 背景层使用固定定位覆盖整个视口，内容层使用相对定位和背景模糊确保可读性。 响应式设计确保在各种屏幕尺寸上都有良好表现。

本页使用

三色对称渐变

包含紫、蓝、红三色的对称渐变，色彩过渡更丰富，视觉效果更强烈。

纯色对称渐变

单一颜色的对称渐变，从边缘紫色向内容区域逐渐变淡，简洁而优雅。

响应式边缘渐变

在移动设备上，边缘渐变区域会自动调整宽度，确保在小屏幕上内容区域依然清晰可读。 渐变比例保持不变，但可见的渐变区域会根据屏幕宽度自动缩放，提供一致的设计体验。

对称渐变CSS代码 
.edge-gradient-symmetric {
  background: linear-gradient(
    90deg,
    /* 左侧渐变 */
    rgba(139, 92, 246, 1) 0%,
    rgba(139, 92, 246, 0.8) 15%,
    rgba(59, 130, 246, 0.6) 30%,
    rgba(239, 68, 68, 0.3) 40%,
    rgba(255, 255, 255, 0) 50%,
    /* 右侧渐变（对称） */
    rgba(255, 255, 255, 0) 50%,
    rgba(239, 68, 68, 0.3) 60%,
    rgba(59, 130, 246, 0.6) 70%,
    rgba(139, 92, 246, 0.8) 85%,
    rgba(139, 92, 246, 1) 100%
  );
}
